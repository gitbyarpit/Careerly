# Careerly

An AI-powered career assistance platform that helps students and job seekers prepare for their careers through intelligent tools for resume analysis, interview preparation, and personalized career guidance.

## Features

* AI-powered career assistance
* Resume analysis and feedback
* Interview preparation
* Personalized career recommendations
* Clean and responsive user interface
* Secure authentication
* Fast and scalable architecture

## Tech Stack

### Frontend

* React.js
* Tailwind CSS
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* PostgreSQL / Prisma ORM

### AI & APIs

* OpenAI API
* Other AI integrations (if applicable)

## Installation

### Clone the repository

```bash
git clone https://github.com/gitbyarpit/Careerly.git
cd Careerly
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file and add the required environment variables.

Example:

```env
DATABASE_URL=
OPENAI_API_KEY=
JWT_SECRET=
```

### Start the development server

```bash
npm run dev
```
